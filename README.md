# Стебель

Учебный интернет-магазин цветов: адаптивный каталог, фильтры, сортировка, подробности букета, корзина и пробный заказ без оплаты.

## Запуск

Откройте `dist/index.html` в браузере или запустите любой статический сервер для папки `dist`.
Сборка и установка зависимостей не требуются. Основа: HTML, CSS и JavaScript.

## Файлы

- `dist/index.html` — структура страницы.
- `dist/styles.css` — оформление и мобильная версия.
- `dist/app.js` — товары, фильтры и корзина.
- `dist/assets/bouquets.png` — сгенерированные демонстрационные изображения.

Товары, цены и изображения демонстрационные. Оплата, отправка заявок и реальная доставка не подключены. Корзина, текст открытки и последний пробный заказ хранятся в localStorage этого браузера. Они не отправляются на сервер.

Изображения созданы встроенным ImageGen. Это фотографии для учебного макета, а не снимки реальных товаров. Промпт: `ASSETS.md`.
